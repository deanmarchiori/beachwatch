# beachwatch  

This is a sample repository for the case study covered in [Data Science Workflows in R](https://datasciworkflows.netlify.app/)  

## About  

branch `main`: A demonstration of a typical monolithic notebook style analysis  
branch `production-ready`: A demonstration of a refactoring of the above to include elements of production-ready code.  

To clone the codebase from Github:

```{r} 
usethis::create_from_github("deanmarchiori/beachwatch", fork = FALSE)
```
